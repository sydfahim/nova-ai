# Nova

React 19 + TanStack Start + Vite + Tailwind CSS application backed by Supabase.

## Development

- Use the existing local development server when available.
- Run `npm run build` and `npm run lint` after code changes.
- Keep secrets in environment variables; never put service-role keys in browser code.
- Add Supabase schema changes as migrations under `supabase/migrations`.
- Treat `NOVA_STATUS.md` as the current implementation audit and `roadmap.md` as planned direction.
